# Документация P2P File Share

Добро пожаловать в документацию по проекту P2P File Share.

Этот проект представляет собой веб-приложение для обмена файлами, работающее по принципу peer-to-peer (P2P) через WebRTC. Оно позволяет пользователям напрямую передавать файлы друг другу через браузер или с помощью команды `curl`, обеспечивая безопасность и конфиденциальность.

## Структура документации

Документация разделена на следующие разделы:

*   **[Архитектура](ARCHITECTURE.md):** Подробное описание компонентов системы, их взаимодействия и потоков данных.
*   **[API](API.md):** Техническая документация по HTTP API, используемому для загрузки и скачивания файлов через `curl`.
*   **[Безопасность](SECURITY.md):** Описание всех мер безопасности, реализованных в приложении.
*   **[Развертывание](DEPLOYMENT.md):** Пошаговое руководство по установке и настройке приложения на вашем сервере.
