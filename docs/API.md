# API Документация P2P File Share

Этот документ описывает HTTP API, предоставляемое сервером для взаимодействия с помощью `curl`.

## Базовый URL

`https://<ваш-домен>`

## Эндпоинты

### Загрузка файла (PUT)

Загружает файл на сервер и возвращает одноразовую ссылку для скачивания.

**URL**
```
PUT /<filename>
```

**Заголовки**
| Заголовок | Обязательный | Описание |
| :--- | :--- | :--- |
| `X-Filename` | Нет | Оригинальное имя файла. Если не указано, будет использовано имя из URL или `file.bin`. |

**Тело запроса**

Бинарные данные загружаемого файла.

**Пример запроса**
```bash
# С указанием имени в URL
curl -T "мой_файл.docx" https://station307.suhail35.ru/мой_файл.docx

# С указанием имени в заголовке
curl -H "X-Filename: мой_файл.docx" -T "-" https://station307.suhail35.ru/ < мой_файл.docx
```

**Ответ**

**Код состояния:** `200 OK`

**Тело ответа (text/plain)**
```
Файл загружен: мой_файл.docx
Ссылка: https://station307.suhail35.ru/d/abc12345
Команда для скачивания:
    curl -o "мой_файл.docx" https://station307.suhail35.ru/d/abc12345
```

### Скачивание файла (GET)

Скачивает файл по его уникальному идентификатору. Файл удаляется с сервера сразу после успешной передачи.

**URL**
```
GET /d/<file_id>
```

**Параметры пути**
| Параметр | Описание |
| :--- | :--- |
| `file_id` | Уникальный идентификатор файла, полученный при загрузке. |

**Пример запроса**
```bash
curl -o "мой_файл.docx" https://station307.suhail35.ru/d/abc12345
```

**Ответ**

**Код состояния:** `200 OK`

**Заголовки ответа**
| Заголовок | Значение | Описание |
| :--- | :--- | :--- |
| `Content-Disposition` | `attachment; filename="<original_name>"` | Указывает браузеру или `curl` сохранить файл с оригинальным именем. |
| `Content-Type` | `application/octet-stream` | Указывает, что передаются бинарные данные. |

**Тело ответа**

Бинарные данные файла.

**Особенности для `curl`**

При обнаружении `curl` в заголовке `User-Agent`, сервер создает временную копию файла с простым ASCII-именем (например, `file_abc12345.bin`) для избежания проблем с кодировкой. Эта копия также удаляется после скачивания.

### Проверка работоспособности (GET)

Проверяет, что сервер работает корректно.

**URL**
```
GET /health
```

**Пример запроса**
```bash
curl https://station307.suhail35.ru/health
```

**Ответ**

**Код состояния:** `200 OK`

**Тело ответа (application/json)**
```json
{"status":"ok"}
```

## Ошибки

**Код состояния:** `404 Not Found`

**Описание:** Файл с указанным `file_id` не найден. Это может означать, что файл уже был скачан и удален, срок его хранения истек (1 час), или ID введен неверно.
